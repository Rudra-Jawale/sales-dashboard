# sales-dashboard
"Power BI dashboard analyzing sales "
📊 Adidas Sales Dashboard – Power BI

An interactive Power BI dashboard designed to analyze Adidas sales performance across regions, products, and time periods.

This project demonstrates data modeling, DAX calculations, and business intelligence visualization techniques using Microsoft Power BI.

🎯 Project Objectives
- Analyze overall sales performance.
- Track revenue, profit, and units sold.
- Identify top-performing products and regions.
- Monitor monthly and yearly sales trends.
- Provide interactive insights for decision-making.

📊 Key Performance Indicators (KPIs)
- 💰 Total Revenue
- 📈 Total Profit
- 📦 Total Units Sold
- 📊 Profit Margin (%)
- 📅 Monthly & Yearly Growth Trends

📌 Dashboard Pages & Features
🔹 1. Sales Overview
- KPI summary cards
- Revenue & profit trend analysis
- Sales distribution by region

🔹 2. Product Performance
- Top-selling products
- revenue by category
- units sold by product type
- Profit contribution by product

🔹 3. Regional Analysis
- Sales by region/country
- Regional profit comparison
- Interactive geographic visuals

🔹 4. Time Analysis
- Monthly & yearly trends
- Seasonal insights
- Growth comparisons

🛠️ Tools & Technologies Used
- Microsoft Power BI Desktop
- Power Query (Data Transformation)
- DAX (Data Analysis Expressions)
- Data Modeling (Star Schema)
- Interactive Visualizations
